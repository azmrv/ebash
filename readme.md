# 🚀 Автоматическая настройка окружения разработки на Ubuntu

Этот проект предоставляет **полный набор скриптов** для автоматической установки и настройки рабочей станции разработчика на базе **Ubuntu 24.04 / 26.04 LTS**. Он включает установку:

- Системных обновлений и базовых пакетов
- Docker, Docker Compose, Buildx
- Инструментов разработки: **Go, Rust, Node.js, VS Code, Google Chrome**
- Полезных утилит: **far2l, bat, exa, fzf, ripgrep, fd-find, tmux, jq, httpie, tldr, Git LFS**
- Развёртывание **Forgejo** (Git-сервер) через Docker Compose
- Настройку безопасности: **UFW, Fail2ban, харденинг ядра, автоматические обновления**
- **SSH Certificate Authority (CA)** для централизованного управления доступом
- Восстановление пользовательских конфигураций (dotfiles)

Все скрипты объединены в **интерактивное меню** (`setup.sh`), которое позволяет выполнять установку по частям или целиком.

## 🧩 Что делает каждый скрипт?

| Скрипт | Назначение |
|--------|------------|
| `setup.sh` | **Главное меню** – позволяет выбрать и запустить любой из скриптов по отдельности или выполнить полную установку (этап 1 + этап 2). |
| `install_system.sh` | Обновляет систему, устанавливает базовые пакеты, Docker, UFW, автообновления. **Требует перезагрузки** после завершения. |
| `install_dev_tools.sh` | Устанавливает Go, Rust, Node.js LTS, VS Code, Google Chrome. Настраивает Git (имя, email, ветка `main`, редактор `code`), генерирует SSH-ключ Ed25519. |
| `install_software.sh` | Устанавливает дополнительные утилиты: `far2l`, `bat`, `exa`, `fzf`, `ripgrep`, `fd-find`, `tmux`, `jq`, `httpie`, `tldr`, `git-lfs`. Добавляет удобные алиасы в `~/.bashrc`. |
| `restore_configs.sh` | Восстанавливает файлы конфигураций из папки `configs/` в домашний каталог, создавая резервные копии существующих файлов. Автоматически добавляет точку к файлам в корне (dotfiles). |
| `deploy_forgejo.sh` | Разворачивает Forgejo в Docker Compose с ограничениями CPU (2 ядра) и памяти (4 ГБ). Открывает порты `3000` (web) и `2222` (SSH-доступ для Git). |
| `setup_security.sh` | **Расширенная безопасность:** смена порта SSH, отключение паролей, UFW с rate limiting, Fail2ban (чтение логов через systemd), защита `/tmp`, таймаут сессий, опциональное отключение IPv6, блокировка Ctrl+Alt+Del, харденинг ядра (защита от IP-спуфинга, SYN-флуда, ICMP-редиректов). |
| `setup_ssh_ca.sh` | **SSH Certificate Authority:** генерирует CA-ключи, настраивает сервер на доверие подписанным сертификатам, подписывает текущий пользовательский ключ. Позволяет управлять доступом централизованно. |
| `create_setup.sh` | Собирает текущие конфиги и генерирует скрипты `install_software.sh` и `restore_configs.sh` в папке `~/system_setup`. Этот пакет можно скопировать на другую машину и развернуть окружение одной командой. |

## 🚀 Запуск

1. **Клонируйте репозиторий** или скопируйте папку `setup/` в домашнюю директорию.
2. Перейдите в папку `setup/`:
   ```bash
   cd ~/system/nix/setup
   ```
3. Дайте права на выполнение всем скриптам:
   ```bash
   chmod +x *.sh
   ```
4. Запустите главное меню:
   ```bash
   ./setup.sh
   ```

**Меню предложит вам выбрать нужный пункт** – вы можете установить систему поэтапно или всё сразу.

### Рекомендуемый порядок для новой системы:

1. Запустить **пункт 1** – системная установка (после завершения **перезагрузиться**).
2. После перезагрузки запустить **пункт 2** – инструменты разработки.
3. **Пункт 5** – дополнительные утилиты.
4. **Пункт 6** – развёртывание Forgejo.
5. **Пункт 3** – восстановление конфигураций (если есть файлы в `configs/`).
6. **Пункт 8** – настройка безопасности SSH (меняет порт, включает Fail2ban и т.д.).
7. **Пункт 9** – настройка SSH CA (для централизованного доступа по сертификатам).

## 🔐 Особенности безопасности

- **SSH-доступ** защищён ключами (пароль отключён).
- **Порт SSH** меняется на случайный (2000–65000), чтобы скрыть службу от сканеров.
- **UFW** ограничивает частоту подключений к SSH (защита от брутфорса).
- **Fail2ban** банит IP после 3 неудачных попыток.
- **Ядро** настроено на защиту от IP-спуфинга, SYN-флуда и ICMP-редиректов.
- **Автоматические обновления** безопасности включены.
- **SSH CA** позволяет выдавать сертификаты с ограниченным сроком действия вместо добавления ключей в `authorized_keys`.

## 🌐 Работа с Forgejo

После развёртывания Forgejo (пункт 6) ваш Git-сервер будет доступен:

- Веб-интерфейс: `http://<IP_виртуалки>:3000`
- SSH-доступ для Git: `git@<IP_виртуалки>:2222`

Для работы с репозиториями вам нужно:

1. Добавить свой публичный SSH-ключ в профиле Forgejo (вкладка «SSH / GPG ключи»).
2. Настроить клиентский `~/.ssh/config` для использования нужного ключа (см. скрипт `setup_ssh_ca.sh`).
3. Клонировать репозитории через `git clone ssh://git@<IP>:2222/<ваш_логин>/<репозиторий>.git`.

Подробные инструкции выводятся в конце скриптов `deploy_forgejo.sh` и `setup_ssh_ca.sh`.

## 🧪 Как создать портативный пакет для другой машины?

Если вы хотите перенести ваши настройки на новую Ubuntu без клонирования всего репозитория, выполните:

```bash
./create_setup.sh
```

В папке `~/system_setup` появится готовый набор:
- `configs/` – ваши конфиги (`.bashrc`, `.gitconfig`, настройки VS Code и др.)
- `install_software.sh` – скрипт установки ПО (адаптированный под вашу систему)
- `restore_configs.sh` – скрипт восстановления конфигов

Скопируйте эту папку на новую машину и выполните:
```bash
sudo ./install_software.sh   # установка ПО
sudo reboot                  # перезагрузка
./restore_configs.sh         # восстановление настроек
```

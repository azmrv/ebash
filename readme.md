Отличная идея! Создание такого скрипта — это классическая практика, известная как управление "dotfiles". Она позволяет быстро восстановить привычное рабочее окружение на новой машине или синхронизировать его между несколькими компьютерами.
Я подготовил для вас главный скрипт create_setup.sh, который решает обе ваши задачи:
1.
Собирает важные файлы конфигурации из вашей текущей системы.
2.
Генерирует два других скрипта: install_software.sh (для установки ПО) и restore_configs.sh (для восстановления настроек).
Всё это будет аккуратно сложено в одну папку ~/system_setup, которую вы сможете скопировать на флешку или в облако.
Как это работает
Вы запускаете один-единственный скрипт create_setup.sh. Он автоматически:
•
Создаст директорию ~/system_setup.
•
Скопирует в неё ваши текущие настройки (Git, SSH, Bash и т.д.).
•
Создаст в ней install_software.sh — готовый скрипт для установки Docker, Go, Python и других утилит на новой системе.
•
Создаст в ней restore_configs.sh — скрипт для восстановления ваших настроек из этой папки.
Главный скрипт
Сохраните этот код в файл с именем create_setup.sh в вашей домашней директории.
